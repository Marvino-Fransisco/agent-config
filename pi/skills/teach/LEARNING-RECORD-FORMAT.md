# Learning record format

Save each record as `learning-records/0001-<dash-case-name>.md`, incrementing the highest existing number. Capture one meaningful observation or mission change, not a recap of every lesson. Distinguish demonstrated ability from untested understanding.

```markdown
# <Insight, skill, or mission change>

Date: <YYYY-MM-DD>

## Evidence

<What the learner recalled, demonstrated, struggled with, or explicitly changed. Link the lesson when applicable.>

## Implication

<What the evidence means for the learning plan.>

## Next practice

<What to revisit, test, or build on in a later session.>
```
