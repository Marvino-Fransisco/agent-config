# Mission format

Write `MISSION.md` using these headings. Keep the mission short and use the learner's own words where possible.

```markdown
# <Topic>

## Why I want to learn this

<The real situation, problem, or interest behind the goal.>

## What I want to be able to do

<An observable outcome the learner can practice or demonstrate.>

## Constraints

<Only constraints that affect the lesson plan, such as time, tools, or prior experience.>
```
